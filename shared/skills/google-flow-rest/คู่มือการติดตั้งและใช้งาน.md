# คู่มือติดตั้งและใช้งาน Google Flow REST สำหรับ Codex และ Claude Code

คู่มือนี้ใช้สำหรับติดตั้งสกิล `google-flow-rest` ใน Codex หรือ Claude Code ของสมาชิกทีม และเชื่อมต่อ Google Flow ผ่าน REST API ของ useapi.net

> **สำคัญ:** useapi.net เป็นบริการภายนอก ไม่ใช่ Google API อย่างเป็นทางการ การสร้างวิดีโอจะหักเครดิตจากบัญชี Google Flow ที่เชื่อมไว้ ไม่ใช่เครดิต Codex, Gemini API, Vertex AI หรือ Fuzion

## 1. สิ่งที่ต้องเตรียม

- Codex หรือ Claude Code ที่รองรับ Agent Skills แบบโฟลเดอร์
- Python 3
- บัญชี useapi.net พร้อม API token
- บัญชี Google สำหรับเชื่อม Google Flow แนะนำให้ใช้บัญชีเฉพาะงาน
- เครดิต Google Flow เพียงพอ
- `ffprobe` จาก FFmpeg หากต้องการตรวจไฟล์วิดีโอหลังดาวน์โหลด

## 2. ติดตั้งสกิล

### วิธีง่าย ไม่ใช้คำสั่ง

แนบ ZIP แล้วบอก Codex ว่าให้ติดตั้งเป็นสกิล หรือบอก Claude Code ว่าให้ติดตั้งเป็น Personal Skill ที่ `~/.claude/skills/google-flow-rest` ผู้ช่วยจะจัดการคำสั่งด้านล่างแทนผู้ใช้

### Codex — macOS หรือ Linux

### macOS หรือ Linux

1. แตกไฟล์ `google-flow-rest.zip`
2. เปิด Terminal ในโฟลเดอร์ที่แตกไฟล์
3. รันคำสั่ง:

```bash
mkdir -p "$HOME/.codex/skills"
cp -R google-flow-rest "$HOME/.codex/skills/google-flow-rest"
```

4. ปิดและเปิด Codex ใหม่
5. ทดสอบเรียกสกิลในแชต:

```text
$google-flow-rest ช่วยตรวจบัญชี Google Flow ที่เชื่อมอยู่
```

### Codex — Windows PowerShell

```powershell
New-Item -ItemType Directory -Force "$HOME\.codex\skills"
Copy-Item -Recurse -Force ".\google-flow-rest" "$HOME\.codex\skills\google-flow-rest"
```

จากนั้นปิดและเปิด Codex ใหม่

### Claude Code — macOS หรือ Linux

```bash
mkdir -p "$HOME/.claude/skills"
cp -R google-flow-rest "$HOME/.claude/skills/google-flow-rest"
```

สำหรับการติดตั้งเฉพาะโปรเจกต์ ให้คัดลอกทั้งโฟลเดอร์ไปที่ `.claude/skills/google-flow-rest` ภายในโปรเจกต์แทน

### Claude Code — Windows PowerShell

```powershell
New-Item -ItemType Directory -Force "$HOME\.claude\skills"
Copy-Item -Recurse -Force ".\google-flow-rest" "$HOME\.claude\skills\google-flow-rest"
```

ทดสอบด้วย `/google-flow-rest` หรือสั่งด้วยภาษาปกติให้ตรวจบัญชี Flow หากเพิ่งสร้างโฟลเดอร์ skills ระดับบนสุดระหว่างเปิด Claude Code ให้ Restart หนึ่งครั้ง

> ตัวอย่างคำสั่งในหัวข้อถัดไปแสดง path ของ Codex หากติดตั้งใน Claude Code ให้เปลี่ยน `$HOME/.codex/skills/google-flow-rest` เป็น `$HOME/.claude/skills/google-flow-rest` หรือใช้วิธีง่ายโดยสั่ง Claude ด้วยภาษาปกติให้ทำแทนทั้งหมด

## 3. สมัครและเชื่อมบัญชี

1. สมัคร useapi.net และรับ API token
2. เปิดคู่มือเชื่อมบัญชีของผู้ให้บริการ: <https://useapi.net/docs/start-here/setup-google-flow>
3. เชื่อมบัญชี Google ที่มีสิทธิ์ใช้ Flow
4. รอจนหน้าตั้งค่าแสดงว่าบัญชีถูกเพิ่มสำเร็จ

แนะนำให้ใช้บัญชี Google แยกสำหรับงาน API เพราะบริการภายนอกจะดูแล session ของบัญชีนั้น ห้ามส่ง token, cookies, รหัสผ่าน หรือรหัสยืนยันให้ผู้อื่นทางแชต

## 4. ตั้งค่าโปรเจกต์

สร้างโฟลเดอร์งานใหม่แล้วเข้าไปในโฟลเดอร์นั้น:

```bash
mkdir my-flow-project
cd my-flow-project
```

คัดลอกไฟล์ตัวอย่างจากสกิล:

```bash
cp "$HOME/.codex/skills/google-flow-rest/assets/.env.example" .env
cp "$HOME/.codex/skills/google-flow-rest/assets/.gitignore.example" .gitignore
```

เปิด `.env` ด้วยโปรแกรมแก้ไขข้อความแล้วใส่ค่าของตนเอง:

```dotenv
USEAPI_TOKEN=ใส่_token_ของผู้ใช้งานคนนี้
GOOGLE_FLOW_EMAIL=อีเมลบัญชีที่เชื่อมกับ Flow
```

ป้องกันไม่ให้ผู้อื่นอ่านไฟล์:

```bash
chmod 600 .env
```

ห้ามใส่ไฟล์ `.env` ลง Git หรือส่งรวมไปกับ ZIP

## 5. ตรวจการเชื่อมต่อ

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" accounts
```

หากเชื่อมสำเร็จ ระบบจะแสดงบัญชี Google Flow และสถานะของ session โดยคำสั่งนี้ไม่สร้างวิดีโอและไม่หักเครดิต

## 6. ทดลองสร้างแบบ Dry-run

Dry-run จะแสดงค่าที่กำลังจะส่ง แต่ยังไม่อัปโหลดภาพ ไม่ส่งงาน และไม่หักเครดิต:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" submit \
  --prompt "ผู้หญิงเดินในสวนยามเย็น กล้องติดตามอย่างนุ่มนวล" \
  --model omni-flash \
  --aspect-ratio portrait \
  --resolution 720p \
  --duration 10
```

ตรวจโมเดล, แนวภาพ, ความละเอียด, ระยะเวลา, จำนวนคลิป และบัญชีให้ถูกต้องก่อนยืนยัน

## 7. ส่งงานจริง

เมื่อผู้ใช้งานอนุมัติการหักเครดิตสำหรับค่าที่แสดงแล้ว จึงเพิ่ม `--confirm-spend`:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" submit \
  --prompt "ผู้หญิงเดินในสวนยามเย็น กล้องติดตามอย่างนุ่มนวล" \
  --model omni-flash \
  --aspect-ratio portrait \
  --resolution 720p \
  --duration 10 \
  --confirm-spend
```

ระบบจะคืน Job ID และบันทึกผลตอบกลับไว้ในโฟลเดอร์ `outputs/jobs`

## 8. สร้างวิดีโอจากภาพ

ใช้ภาพเริ่มต้น:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" submit \
  --prompt "ตัวละครในภาพเดินเข้าหากล้องอย่างเป็นธรรมชาติ" \
  --model omni-flash \
  --aspect-ratio portrait \
  --resolution 720p \
  --duration 10 \
  --start-image "/absolute/path/character.png"
```

เพิ่มภาพอ้างอิงได้หลายภาพด้วยการใส่ `--reference-image` ซ้ำ:

```bash
  --reference-image "/absolute/path/character.png" \
  --reference-image "/absolute/path/location.png"
```

ทำ Dry-run ก่อน แล้วจึงเรียกคำสั่งเดิมพร้อม `--confirm-spend`

## 9. ตรวจสถานะและดาวน์โหลด

ตรวจครั้งเดียว:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" status "JOB_ID"
```

รอจนจบและดาวน์โหลด:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" wait "JOB_ID" \
  --download \
  --output-dir outputs
```

`processing` หมายถึงงานยังไม่เสร็จ ห้ามรายงานว่าได้รับวิดีโอแล้วจนกว่าจะเป็น `completed` และมีไฟล์ดาวน์โหลดจริง

## 10. ส่งงานหลายคลิปด้วย CSV

คัดลอกไฟล์ตัวอย่าง:

```bash
cp "$HOME/.codex/skills/google-flow-rest/assets/batch.example.csv" reviewed.csv
```

คอลัมน์สำคัญ:

| คอลัมน์ | ความหมาย |
|---|---|
| `id` | ชื่อหรือหมายเลขช็อต |
| `status` | ส่งเฉพาะแถวที่เป็น `Ready` |
| `prompt` | คำสั่งสร้างวิดีโอ |
| `model` | โมเดลที่จะใช้ |
| `aspect_ratio` | เช่น `portrait` |
| `resolution` | `360p` หรือ `720p` ตามโมเดล |
| `duration` | 4, 6, 8 หรือ 10 วินาทีตามโมเดล |
| `count` | จำนวนผลลัพธ์ต่อคำขอ |
| `start_image` | path ภาพเริ่มต้น |
| `reference_images` | หลาย path คั่นด้วยเครื่องหมาย `;` |
| `job_id` | ระบบเขียนกลับหลังส่งสำเร็จ |
| `error` | ข้อผิดพลาดของแถวนั้น |

ดูรายการที่จะส่งโดยไม่เสียเครดิต:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" batch reviewed.csv
```

จำกัดรอบทดลอง เช่น 2 งาน:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" batch reviewed.csv --max-jobs 2
```

หลังตรวจและอนุมัติแล้ว:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" batch reviewed.csv \
  --max-jobs 2 \
  --confirm-spend
```

หลังส่งสำเร็จ ระบบเขียน Job ID กลับลง CSV ทันที แถวนั้นจึงไม่ถูกส่งซ้ำเมื่อรันอีกรอบ

## 11. ตรวจไฟล์วิดีโอ

```bash
ffprobe -v error \
  -show_entries format=duration,size \
  -show_entries stream=codec_name,width,height \
  -of json "outputs/ชื่อไฟล์.mp4"
```

ตรวจว่าความยาว ขนาดภาพ codec และขนาดไฟล์ตรงกับงานที่สั่ง ผู้ให้บริการอาจใช้คำเรียก 480P หรือ 720P แต่ขนาดพิกเซลจริงอาจต่างกัน จึงควรตรวจไฟล์จริงเสมอ

## 12. ปัญหาที่พบบ่อย

### Missing USEAPI_TOKEN

ตรวจว่า `.env` อยู่ในโฟลเดอร์ที่กำลังรันคำสั่ง หรือระบุไฟล์ก่อนชื่อคำสั่ง:

```bash
python3 "$HOME/.codex/skills/google-flow-rest/scripts/google_flow_rest.py" \
  --env "/absolute/path/.env" accounts
```

### บัญชีไม่ปรากฏหรือ session หมดอายุ

กลับไปยังหน้าตั้งค่า useapi.net และเชื่อมบัญชี Google Flow ใหม่ แล้วรัน `accounts` อีกครั้ง

### ตั้งค่าระยะเวลาหรือความละเอียดไม่ได้

แต่ละโมเดลรองรับค่าไม่เท่ากัน ตรวจเอกสารปัจจุบันที่ <https://useapi.net/docs/api-google-flow-v1> ห้ามเปลี่ยนสเปกเองโดยไม่แจ้งผู้ใช้งาน

### งานล้มเหลว

เก็บข้อความผิดพลาดและ Job ID ไว้ ห้ามส่งซ้ำอัตโนมัติ เพราะอาจเกิดค่าใช้จ่ายซ้ำ ต้องขออนุมัติรอบใหม่ก่อน

## 13. Checklist ก่อนส่งงานจริง

- บัญชีใน `accounts` เป็นบัญชีที่ถูกต้อง
- เครดิต Google Flow เพียงพอ
- Dry-run แสดงจำนวนงานและสเปกตรงตามที่ตกลง
- ภาพอ้างอิงเป็นไฟล์ที่ถูกต้อง
- ผู้ใช้งานอนุมัติยอดและสเปกแล้ว
- เพิ่ม `--confirm-spend` เฉพาะรอบที่อนุมัติ
- เก็บ CSV และ Job ID หลังส่ง
- รอ `completed`, ดาวน์โหลด และตรวจด้วย `ffprobe`

## 14. เรียกใช้ผ่าน Codex หรือ Claude Code

หลังติดตั้ง สามารถสั่งด้วยภาษาธรรมชาติ เช่น:

```text
$google-flow-rest ตรวจบัญชี Flow ให้หน่อย แต่ยังไม่ต้องสร้างวิดีโอ
```

ใน Claude Code ใช้ `/google-flow-rest` แทน `$google-flow-rest` หรือสั่งด้วยภาษาปกติได้ เพราะ Claude สามารถเลือกใช้สกิลอัตโนมัติเมื่อคำขอตรงกับ description

```text
$google-flow-rest เตรียม Dry-run วิดีโอแนวตั้ง 720P 10 วินาทีจากภาพนี้
```

```text
$google-flow-rest ตรวจ CSV นี้และสรุปจำนวน Ready ก่อน ห้ามหักเครดิตจนกว่าผมจะยืนยัน
```
