# การวางแผนข้อมูลเพื่อเลือกฐานราก

## ใช้เมื่อ
ต้องตัดสินใจประเภทฐานรากหรือบอกว่าต้องมีข้อมูลอะไรก่อนเลือก

## ข้อมูลนำเข้าที่ต้องถามก่อน
- รายงานเจาะสำรวจดินและระดับน้ำใต้ดิน
- น้ำหนักที่เสา
- ผังอาคารและอาคารข้างเคียง
- ข้อจำกัดการเข้าถึงของเครื่องจักร
- ผลกระทบจากการตอกเข็ม (สั่นสะเทือน เสียง)

## ลำดับการให้เหตุผล
1. **ตรวจว่ามีข้อมูลดินครอบคลุมหรือไม่** — เหตุผล: ไม่มีข้อมูลดิน เลือกฐานรากไม่ได้ ให้ระบุว่าขาดข้อมูล
2. **ประเมินน้ำหนักเบื้องต้นและความไวต่อการทรุดตัว** — เหตุผล: ชนิดโครงสร้างกำหนดทรุดตัวที่ยอมรับได้
3. **เปรียบเทียบฐานตื้น ฐานแผ่ เข็มตอก เข็มเจาะ** — เหตุผล: แต่ละแบบเหมาะกับดิน อาคารข้างเคียง และเครื่องจักรต่างกัน
4. **ตรวจข้อจำกัดข้างเคียงและการก่อสร้าง** — เหตุผล: การตอกอาจกระทบอาคารใกล้เคียง
5. **สรุปทางเลือกพร้อมสิ่งที่ยังขาด** — เหตุผล: ให้วิศวกรคำนวณและเสนอชนิดฐานราก
6. **วางแผนการตรวจและทดสอบระหว่างก่อสร้าง** — เหตุผล: สภาพดินจริงอาจต่างจากรายงาน

## จุดประสานข้ามสาขาที่ต้องตรวจ
- ท่อระบายน้ำเสียและบ่อตรวจเทียบฐานราก
- สาธารณูปโภคใต้ดิน
- อาคารข้างเคียง

## ต้องให้ผู้เชี่ยวชาญหรือหน่วยงานอนุมัติเมื่อ
- การเลือกและการออกแบบฐานรากต้องให้วิศวกรที่ได้รับอนุญาต
- ผลทดสอบดินและการรับรองเข็ม

## ผลลัพธ์ที่ต้องให้ผู้ใช้
- สรุปความเข้าใจ (การใช้ ที่ดิน ข้อจำกัด)
- คำแนะนำพร้อมเหตุผลและทางเลือก
- รายการข้อมูลและการคำนวณที่ยังขาด
- ป้ายหลักฐาน (VERIFIED / ASSUMPTION / RULE OF THUMB / REQUIRES CALCULATION / REQUIRES APPROVAL)
- ข้อความให้ผู้ประกอบวิชาชีพที่ได้รับอนุญาตตรวจสอบ

## กรณีศึกษา
ยังไม่ได้เขียนกรณีศึกษาเต็มรูปแบบ ต้องเขียนหลังอ่านแหล่งอ้างอิงจริง โดยระบุข้อมูลตั้งต้น ข้อมูลที่ขาด แนวคิดสถาปัตยกรรมและโครงสร้างเบื้องต้น ข้อมูลสำรวจดินที่ต้องมี การประสานงานระบบ การตรวจกฎหมาย ลำดับก่อสร้าง ข้อแลกเปลี่ยน และการคำนวณที่ยังไม่เสร็จ: การเลือกฐานรากบ้านสองชั้นและตึกแถว
