# การวางระบบโครงสร้าง

## ใช้เมื่อ
วางผังเสา ระบบพื้น และเสถียรภาพของอาคาร

## ข้อมูลนำเข้าที่ต้องถามก่อน
- การใช้งานและโหลด
- ผังสถาปัตยกรรม
- ข้อมูลดินและฐานราก
- ความสูงใต้คานที่ยอมได้
- งานระบบที่ต้องผ่านโครงสร้าง

## ลำดับการให้เหตุผล
1. **เสนอกริดเสาจากผังสถาปัตยกรรมและช่วงพาด** — เหตุผล: กริดตรงกับการใช้งานและสอดคล้องกับระบบพื้นและฐาน
2. **ตรวจเส้นทางน้ำหนักจากหลังคาถึงดิน** — เหตุผล: ช่วงที่ไม่ต่อเนื่องเป็นความเสี่ยง
3. **เลือกระบบต้านแรงด้านข้าง** — เหตุผล: ลมและแผ่นดินไหวต้องการผนังหรือโครงที่ออกแบบ
4. **ตรวจการประสานช่องทะลุ ท้องคาน และงานระบบ** — เหตุผล: การชนกับท่อและทางหนีไฟ
5. **ระบุการคำนวณที่ยังขาด** — เหตุผล: ไม่ระบุขนาดชิ้นส่วนก่อนคำนวณจริง

## จุดประสานข้ามสาขาที่ต้องตรวจ
- เสากับประตู ทางเดิน ที่จอดรถ
- คานกับท่อและท่อลม
- ช่องเปิดพื้นกับเส้นท่อ

## ต้องให้ผู้เชี่ยวชาญหรือหน่วยงานอนุมัติเมื่อ
- การกำหนดระบบโครงสร้าง ขนาดชิ้นส่วน และเหล็กเสริม ต้องให้วิศวกรโครงสร้างที่ได้รับอนุญาต

## ผลลัพธ์ที่ต้องให้ผู้ใช้
- สรุปความเข้าใจ (การใช้ ที่ดิน ข้อจำกัด)
- คำแนะนำพร้อมเหตุผลและทางเลือก
- รายการข้อมูลและการคำนวณที่ยังขาด
- ป้ายหลักฐาน (VERIFIED / ASSUMPTION / RULE OF THUMB / REQUIRES CALCULATION / REQUIRES APPROVAL)
- ข้อความให้ผู้ประกอบวิชาชีพที่ได้รับอนุญาตตรวจสอบ

## กรณีศึกษา
ยังไม่ได้เขียนกรณีศึกษาเต็มรูปแบบ ต้องเขียนหลังอ่านแหล่งอ้างอิงจริง โดยระบุข้อมูลตั้งต้น ข้อมูลที่ขาด แนวคิดสถาปัตยกรรมและโครงสร้างเบื้องต้น ข้อมูลสำรวจดินที่ต้องมี การประสานงานระบบ การตรวจกฎหมาย ลำดับก่อสร้าง ข้อแลกเปลี่ยน และการคำนวณที่ยังไม่เสร็จ: ตึกแถวสามชั้นและอพาร์ตเมนต์สิบชั้น
