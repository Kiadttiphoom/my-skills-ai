# การวางระบบประปา ไฟฟ้า ปรับอากาศ และดับเพลิง

## ใช้เมื่อ
วางระบบงานระบบอาคารและประสานกับโครงสร้าง

## ข้อมูลนำเข้าที่ต้องถามก่อน
- การใช้งานและอุปกรณ์
- โหลดไฟ น้ำ ความร้อน
- ผังและระดับ
- จุดต่อสาธารณูปโภค
- ข้อกำหนดผู้ให้บริการ (PEA/MEA/MWA/PWA)

## ลำดับการให้เหตุผล
1. **ทำรายการอุปกรณ์และโหลด** — เหตุผล: เป็นฐานของการประเมินทุกสาขา
2. **วางตำแหน่งห้องเครื่อง ตู้ไฟ ถังน้ำ และทางท่อหลัก** — เหตุผล: ทางหลักต้องเข้าถึงซ่อมได้และไม่ชนโครงสร้าง
3. **กำหนดความลาดและระดับท่อน้ำทิ้ง** — เหตุผล: เป็นข้อจำกัดแรงโน้มถ่วงที่ยืดหยุ่นน้อย
4. **วางตำแหน่งตู้ไฟ ปรับอากาศ ท่อลม** — เหตุผล: ตรวจชนกับท่อน้ำและคาน
5. **ตรวจการประสาน (clash)** — เหตุผล: ทุกการแก้ไขระบุผู้อนุมัติ
6. **กำหนดการทดสอบก่อนปิดและก่อนส่งมอบ** — เหตุผล: ตรวจให้พบก่อนซ่อนในผนังและฝ้า

## จุดประสานข้ามสาขาที่ต้องตรวจ
- ท่อน้ำทิ้ง กับ คาน และคานคอดิน
- ท่อน้ำ กับ ตู้ไฟ
- ท่อลม กับ ท้องคานและฝ้า
- ท่อน้ำทิ้งแอร์กับจุดระบาย

## ต้องให้ผู้เชี่ยวชาญหรือหน่วยงานอนุมัติเมื่อ
- ระบบไฟฟ้า ประปา บำบัดน้ำเสีย ปรับอากาศ และดับเพลิง ต้องให้ผู้ประกอบวิชาชีพที่เกี่ยวข้องตรวจ
- ข้อกำหนดผู้ให้บริการสาธารณูปโภค

## ผลลัพธ์ที่ต้องให้ผู้ใช้
- สรุปความเข้าใจ (การใช้ ที่ดิน ข้อจำกัด)
- คำแนะนำพร้อมเหตุผลและทางเลือก
- รายการข้อมูลและการคำนวณที่ยังขาด
- ป้ายหลักฐาน (VERIFIED / ASSUMPTION / RULE OF THUMB / REQUIRES CALCULATION / REQUIRES APPROVAL)
- ข้อความให้ผู้ประกอบวิชาชีพที่ได้รับอนุญาตตรวจสอบ

## กรณีศึกษา
ยังไม่ได้เขียนกรณีศึกษาเต็มรูปแบบ ต้องเขียนหลังอ่านแหล่งอ้างอิงจริง โดยระบุข้อมูลตั้งต้น ข้อมูลที่ขาด แนวคิดสถาปัตยกรรมและโครงสร้างเบื้องต้น ข้อมูลสำรวจดินที่ต้องมี การประสานงานระบบ การตรวจกฎหมาย ลำดับก่อสร้าง ข้อแลกเปลี่ยน และการคำนวณที่ยังไม่เสร็จ: ร้านซักรีดขนาดเล็ก (น้ำ ระบายน้ำ ไฟ ระบายอากาศ)
