# งานปรับปรุงและดัดแปลงอาคารเดิม

## ใช้เมื่อ
เปลี่ยนการใช้ เปิดช่อง ต่อเติม รื้อ หรือปรับปรุงอาคารที่มีอยู่

## ข้อมูลนำเข้าที่ต้องถามก่อน
- แบบเดิมและแบบก่อสร้างจริง (ถ้ามี)
- ปีก่อสร้างและประวัติการดัดแปลง
- สภาพโครงสร้างและความเสียหายที่เห็น
- การใช้อาคารเดิมและใหม่
- โหลดที่เปลี่ยนไป
- ข้อมูลดินและฐานราก (ถ้ามี)

## ลำดับการให้เหตุผล
1. **เก็บข้อมูลแบบเดิมและสภาพจริง** — เหตุผล: ถ้าไม่มีแบบ ต้องจัดทำแบบสำรวจ (สอดคล้องกับแนวคิดใน S-001 ข้อ ๒๐)
2. **ระบุว่าการแก้ไขแตะโครงสร้างหรือไม่** — เหตุผล: อย่าตัด เจาะ หรือรื้อเสา คาน พื้น ผนังรับแรง หรือเข็ม โดยไม่มีวิศวกรโครงสร้างอนุมัติ
3. **ประเมินน้ำหนักที่เปลี่ยน** — เหตุผล: เพิ่มน้ำหนักถือเป็นดัดแปลงตามคู่มือ (S-002)
4. **ตรวจว่าต้องขออนุญาตหรือแจ้ง** — เหตุผล: การเปลี่ยนโครงสร้างคอนกรีตเสริมเหล็กหรือเหล็กโครงสร้างไม่อยู่ในรายการที่ไม่ต้องขออนุญาตตามคู่มือ ต้องตรวจกฎหมายปัจจุบันและเจ้าพนักงานท้องถิ่น
5. **ตรวจระบบเดิม** — เหตุผล: ท่อ สายไฟ ตู้ ท่อน้ำทิ้ง อาจไม่รองรับการใช้ใหม่
6. **ตรวจความปลอดภัยด้านไฟและทางหนี เมื่อเปลี่ยนการใช้** — เหตุผล: การเปลี่ยนการใช้เปลี่ยนข้อกำหนด
7. **วางลำดับงานที่รบกวนผู้ใช้และโครงสร้างน้อยที่สุด** — เหตุผล: ค้ำยันชั่วคราวและการรื้อต้องออกแบบ

## จุดประสานข้ามสาขาที่ต้องตรวจ
- ท่อและสายเดิมกับของใหม่
- เจาะช่องกับโครงสร้าง
- โหลดใหม่กับฐานรากเดิม

## ต้องให้ผู้เชี่ยวชาญหรือหน่วยงานอนุมัติเมื่อ
- ทุกการแตะโครงสร้างต้องให้วิศวกรโครงสร้างที่ได้รับอนุญาต
- การขออนุญาตหรือแจ้งดัดแปลงต่อเจ้าพนักงานท้องถิ่น
- การตรวจประจำปีและตรวจใหญ่ตาม S-001 สำหรับอาคารที่เข้าข่าย

## ผลลัพธ์ที่ต้องให้ผู้ใช้
- สรุปความเข้าใจ (การใช้ ที่ดิน ข้อจำกัด)
- คำแนะนำพร้อมเหตุผลและทางเลือก
- รายการข้อมูลและการคำนวณที่ยังขาด
- ป้ายหลักฐาน (VERIFIED / ASSUMPTION / RULE OF THUMB / REQUIRES CALCULATION / REQUIRES APPROVAL)
- ข้อความให้ผู้ประกอบวิชาชีพที่ได้รับอนุญาตตรวจสอบ

## กรณีศึกษา
ยังไม่ได้เขียนกรณีศึกษาเต็มรูปแบบ ต้องเขียนหลังอ่านแหล่งอ้างอิงจริง โดยระบุข้อมูลตั้งต้น ข้อมูลที่ขาด แนวคิดสถาปัตยกรรมและโครงสร้างเบื้องต้น ข้อมูลสำรวจดินที่ต้องมี การประสานงานระบบ การตรวจกฎหมาย ลำดับก่อสร้าง ข้อแลกเปลี่ยน และการคำนวณที่ยังไม่เสร็จ: การปรับปรุงตึกแถวเดิม
