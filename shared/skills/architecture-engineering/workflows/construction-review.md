# การตรวจแบบและงานก่อสร้าง

## ใช้เมื่อ
ตรวจแบบก่อสร้าง ตรวจหน้างาน ตรวจคุณภาพและความปลอดภัย หรือตรวจอาคารที่ใช้งานอยู่

## ข้อมูลนำเข้าที่ต้องถามก่อน
- แบบทุกสาขาและรายการประกอบแบบ
- ผลทดสอบวัสดุและงานระบบ
- บันทึกหน้างาน
- ขอบเขตการตรวจ

## ลำดับการให้เหตุผล
1. **ตรวจความครบของแบบและการประสานสาขา** — เหตุผล: ปัญหาที่พบในแบบถูกกว่าแก้หน้างาน
2. **ตรวจจุดที่ต้องตรวจก่อนปิดทับ** — เหตุผล: เหล็กเสริม ท่อฝัง กันซึม ท่อน้ำทิ้ง งานไฟ
3. **ตรวจการประสานกับงานฝัง** — เหตุผล: ท่อและสลีฟต้องถูกที่ก่อนเทคอนกรีต
4. **ตรวจความปลอดภัยหน้างาน** — เหตุผล: ค้ำยัน แบบหล่อ ไฟฟ้าชั่วคราว การทำงานบนที่สูง
5. **สำหรับอาคารที่ใช้งานอยู่ ตรวจตามขอบเขตของ S-001 ข้อ ๑๗** — เหตุผล: ความมั่นคง ระบบประกอบอาคาร สมรรถนะอพยพ การบริหารความปลอดภัย
6. **จัดทำรายการข้อบกพร่องพร้อมข้อเสนอแก้ไข** — เหตุผล: เจ้าของต้องมีข้อเสนอเพื่อให้ผ่านเกณฑ์ (สอดคล้อง S-001 ข้อ ๑๙)

## จุดประสานข้ามสาขาที่ต้องตรวจ
- ผลทดสอบท่อและไฟก่อนปิด
- งานฝังกับโครงสร้าง

## ต้องให้ผู้เชี่ยวชาญหรือหน่วยงานอนุมัติเมื่อ
- การวินิจฉัยความเสียหายโครงสร้าง
- การตรวจอาคารตามกฎหมายต้องทำโดยผู้ตรวจสอบที่ขึ้นทะเบียน (S-001) และผู้ตรวจไม่ควรมีส่วนร่วมออกแบบหรือก่อสร้างอาคารเดียวกัน

## ผลลัพธ์ที่ต้องให้ผู้ใช้
- สรุปความเข้าใจ (การใช้ ที่ดิน ข้อจำกัด)
- คำแนะนำพร้อมเหตุผลและทางเลือก
- รายการข้อมูลและการคำนวณที่ยังขาด
- ป้ายหลักฐาน (VERIFIED / ASSUMPTION / RULE OF THUMB / REQUIRES CALCULATION / REQUIRES APPROVAL)
- ข้อความให้ผู้ประกอบวิชาชีพที่ได้รับอนุญาตตรวจสอบ

## กรณีศึกษา
ยังไม่ได้เขียนกรณีศึกษาเต็มรูปแบบ ต้องเขียนหลังอ่านแหล่งอ้างอิงจริง โดยระบุข้อมูลตั้งต้น ข้อมูลที่ขาด แนวคิดสถาปัตยกรรมและโครงสร้างเบื้องต้น ข้อมูลสำรวจดินที่ต้องมี การประสานงานระบบ การตรวจกฎหมาย ลำดับก่อสร้าง ข้อแลกเปลี่ยน และการคำนวณที่ยังไม่เสร็จ: ตรวจแบบร้านซักรีดและตึกแถว
