# วิธีการและลำดับการก่อสร้าง

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ลำดับงานตั้งแต่เตรียมพื้นที่ ฐานราก โครงสร้าง ก่ออิฐ งานระบบ ฉาบ กันซึม ปูกระเบื้อง ฝ้า ทาสี ติดตั้งอุปกรณ์ ทดสอบและส่งมอบ

## 2. หลักการสำคัญ (Fundamental principles)
- งานที่ถูกปิดทับต้องตรวจก่อนปิด
- งานระบบฝังในพื้นและผนังต้องประสานและทดสอบก่อนเทหรือฉาบ
- ทุกขั้นตอนมีข้อกำหนดก่อนเริ่ม ลำดับดำเนินการ จุดตรวจ และข้อบกพร่องที่พบบ่อย
- ความคลาดเคลื่อนของงานก่อนหน้าส่งต่อไปยังงานถัดไป

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- แบบก่อสร้างที่ประสานแล้ว
- ผังเวลาและลำดับงาน
- วัสดุและเครื่องมือ
- แผนตรวจและทดสอบ

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ตรวจแบบและสถานที่ก่อนเริ่ม
2. ลงฐานรากและโครงสร้างตามลำดับ
3. ติดตั้งงานระบบฝังและทดสอบ
4. ก่อฉาบกันซึมและปูผิว
5. ติดตั้งอุปกรณ์ ทดสอบและส่งมอบ

## 5. เชื่อมกับระบบอื่น
- ทุกสาขา: งานฝังและสลีฟต้องทำก่อนเท
- โครงสร้าง: เวลาถอดแบบและรับน้ำหนักระหว่างก่อสร้าง

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- ท่อฝังหายหรือผิดตำแหน่งตอนเท
- ฉาบก่อนทดสอบท่อ
- กันซึมก่อนผิวพื้นลาดเอียงถูกต้อง

## 7. จุดตรวจคุณภาพ (QC)
- ตารางจุดตรวจก่อนเทและก่อนปิดทับ
- บันทึกผลทดสอบ

## 8. ความเข้าใจผิดที่พบบ่อย
- แก้ที่หน้างานทีหลังได้ทุกอย่าง (งานฝังและโครงสร้างแก้ยากและอาจเสี่ยง)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- รายละเอียดแต่ละงานพร้อมแหล่งอ้างอิง
- ตัวอย่างลำดับงานจากกรณีศึกษา
