# วิศวกรรมโครงสร้าง

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ผังเสา ระบบโครงสร้าง เส้นทางถ่ายน้ำหนัก น้ำหนักบรรทุก การรวมแรง เสถียรภาพ การโก่งตัวและการสั่นสะเทือน

## 2. หลักการสำคัญ (Fundamental principles)
- น้ำหนักถ่ายตามลำดับ: พื้น → คาน → เสาหรือผนัง → ฐานราก → ดิน ถ้าขาดช่วงใดการออกแบบไม่สมบูรณ์
- เสาตั้งตามผังโครงสร้าง ช่วงพาด น้ำหนัก และสถาปัตยกรรม ไม่ได้ตั้งตามพื้นที่
- อาคารต้านแรงด้านข้าง (ลม แผ่นดินไหวถ้ามี) ด้วยระบบที่ออกแบบ เช่น ผนังรับแรงเฉือนหรือโครงต้านโมเมนต์
- ความต่อเนื่องและความซ้ำซ้อนของโครงสร้างช่วยลดการพังทลายต่อเนื่อง
- การโก่งตัวและสั่นสะเทือนเป็นเกณฑ์ใช้งาน ไม่ใช่แค่ความแข็งแรง

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- การใช้งานและน้ำหนักบรรทุก
- ผังสถาปัตยกรรม
- ชั้นดินและฐานราก
- ข้อกำหนดกฎหมายและมาตรฐานที่เกี่ยวข้อง
- ข้อจำกัดความสูงใต้คาน

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. วางผังเสาจากสถาปัตยกรรมและช่วงพาดที่เหมาะสม
2. ระบุเส้นทางน้ำหนักและระบบต้านแรงด้านข้าง
3. ประเมินน้ำหนักบรรทุกและการรวมแรงด้วยมาตรฐานที่กำหนด
4. ตรวจการโก่งตัว เสถียรภาพ และรอยต่อ
5. ประสานกับงานระบบและฐานราก

## 5. เชื่อมกับระบบอื่น
- ฐานราก: โหลดที่เสา
- สถาปัตยกรรม: ช่องเปิดและความสูงใต้คาน
- ประปา แอร์: ช่องทะลุคานและพื้น
- คอนกรีตเสริมเหล็ก: การออกแบบรายองค์อาคาร

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- เสาไม่ต่อเนื่องจากบนลงล่าง
- คานขาดการรองรับ
- ช่องเปิดตัดคานหรือพื้นโดยไม่ตรวจ
- ดัดแปลงโดยไม่คิดน้ำหนักเพิ่ม

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจความต่อเนื่องของเส้นทางน้ำหนัก
- ตรวจการประสานช่องทะลุกับวิศวกรโครงสร้าง

## 8. ความเข้าใจผิดที่พบบ่อย
- จำนวนเสาประมาณจากพื้นที่ได้ (ไม่ได้)
- ผนังก่อไม่มีผลต่อโครงสร้าง (มีผลต่อน้ำหนักและความแข็งเกร็งได้)

## 9. ความสัมพันธ์พื้นฐาน (ตำราทั่วไป ใช้เพื่อเข้าใจหลักการเท่านั้น ไม่ใช่สูตรกำหนดขนาด)
- แรงแผ่เป็นเส้นบนคาน w = q × b (q = น้ำหนักแผ่ kN/m², b = ความกว้างพื้นที่ส่งน้ำหนักเข้าคาน m, ได้ kN/m)
- โมเมนต์สูงสุดคานช่วงเดียวรับน้ำหนักแผ่สม่ำเสมอ M = wL²/8 (ความสัมพันธ์ตำรา ใช้เข้าใจหลักการเท่านั้น)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ
- กฎกระทรวงและมาตรฐานด้านน้ำหนักบรรทุก ลม และแผ่นดินไหว ให้ตรวจจากต้นฉบับ (ข้ออ้าง มยผ. ที่ได้มายังเป็น UNVERIFIED)

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงด้านน้ำหนักบรรทุกและการรวมแรง
- ตัวอย่างผังเสาที่ระบุสมมติฐาน
