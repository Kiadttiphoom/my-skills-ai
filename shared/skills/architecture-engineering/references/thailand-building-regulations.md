# กฎหมายและมาตรฐานอาคารของไทย

## 1. ชั้นของข้อกำหนด
กฎหมาย (พ.ร.บ. กฎกระทรวง ข้อบัญญัติ) → มาตรฐานวิศวกรรม (มยผ. วสท. มอก. มาตรฐานสากล) → แนวปฏิบัติทั่วไป → หลักการเบื้องต้น ห้ามนำชั้นล่างมาแสดงเป็นชั้นบน

## 2. สิ่งที่อ่านจริงแล้ว (อ้าง Source ID ใน `RESEARCH_SOURCES.md`)
**จาก S-001 กฎกระทรวงตรวจสอบอาคาร พ.ศ. ๒๕๔๘ (กฎหมายบังคับ; ตรวจเฉพาะข้อความที่ตีพิมพ์ปี ๒๕๔๘ ยังไม่ตรวจการแก้ไข)**
- การตรวจใหญ่ทุก ๕ ปี และการตรวจประจำปี
- ขอบเขตตรวจอย่างน้อย: ความมั่นคงแข็งแรง (ต่อเติมดัดแปลง น้ำหนักบรรทุกที่เปลี่ยน การเปลี่ยนการใช้ วัสดุ การชำรุด การวิบัติ การทรุดตัวฐานราก) ระบบประกอบอาคาร (ลิฟต์ บันไดเลื่อน ไฟฟ้า ปรับอากาศ ประปา ระบายน้ำเสียและบำบัด ระบายน้ำฝน ขยะ ระบายอากาศ ควบคุมมลพิษ ระบบป้องกันและระงับอัคคีภัย) สมรรถนะการอพยพ และระบบบริหารความปลอดภัย
- เกณฑ์การตรวจ: กฎหมายควบคุมอาคารหรือกฎหมายอื่นที่ใช้บังคับ ณ เวลาก่อสร้าง หรือมาตรฐานความปลอดภัยของทางราชการ สภาวิศวกร หรือสภาสถาปนิก
- ถ้าไม่มีแบบอาคารเดิม เจ้าของต้องจัดทำแบบสำหรับตรวจสอบ
- เจ้าของจัดบำรุงรักษาตามคู่มือผู้ผลิตหรือแผนของผู้ตรวจสอบ และเก็บบันทึก
- ผลต่อการออกแบบ: ต้องเผื่อทางเข้าตรวจและซ่อมระบบทุกชนิด และเก็บแบบก่อสร้างจริง (as-built)

**จาก S-002 คู่มือกฎหมายควบคุมอาคาร กรมโยธาธิการและผังเมือง ลงวันที่ ๒๕๕๒ (คำอธิบาย ไม่ใช่ตัวบท; เกณฑ์ตัวเลขอาจเปลี่ยนแล้ว; อ่านเฉพาะหน้าที่มีในไฟล์)**
- นิยาม "ดัดแปลง" รวมการเพิ่มน้ำหนักให้โครงสร้าง เช่น ติดเสาเหล็กบนดาดฟ้า
- การเปลี่ยนโครงสร้างคอนกรีตเสริมเหล็ก คอนกรีตอัดแรง หรือเหล็กโครงสร้าง ไม่อยู่ในรายการดัดแปลงที่ไม่ต้องขออนุญาต
- เอกสารขออนุญาตและข้อยกเว้นแบบแปลน (เช่น บ้านอยู่อาศัยไม่เกินสองชั้นและไม่เกินพื้นที่ที่คู่มือระบุ ในเขต อบต. ที่ไม่ใช่พื้นที่ห้ามก่อสร้าง) — ตรวจตัวเลขกับกฎหมายปัจจุบัน
- อาคารควบคุมการใช้บางประเภทไม่กำหนดพื้นที่ และบางประเภทกำหนดพื้นที่หรือกำลังเครื่องจักร

## 3. ยังไม่ได้ตรวจ (UNVERIFIED)
- มยผ. 1302 ว่าเป็นมาตรฐานแผ่นดินไหว
- มยผ. 1101–1106 (ผลค้นหาพบข้อความตัวอย่างว่าเป็นมาตรฐานกำหนดคุณลักษณะวัสดุโครงสร้าง ฉบับ พ.ศ. ๒๕๖๔ ปรับปรุงครั้งที่ ๑ ยังไม่ได้อ่านต้นฉบับ)
- กฎกระทรวง ฉบับที่ ๖ ว่าด้วยน้ำหนักบรรทุก
- มอก. 24 ว่าเป็นมาตรฐานเหล็กเส้น
- การปรับ ACI เป็นมาตรฐาน วสท. พร้อมตัวคูณความปลอดภัยแบบไทย
- เงื่อนไขการต่อไฟและมิเตอร์ของ PEA/MEA และข้อกำหนดการประปา MWA/PWA
- เกณฑ์ระยะร่น FAR OSR และความสูงตามผังเมืองและข้อบัญญัติท้องถิ่น

## 4. วิธีใช้
- ตอบด้านกฎหมายให้ระบุชั้นของข้อกำหนดและ Source ID เสมอ
- ถ้าไม่มี Source ID ให้เขียนว่า "ต้องตรวจสอบ" พร้อมบอกประเภทเอกสารที่ต้องดู
- ห้ามอ้างว่าอาคารสอดคล้องกฎหมาย จนกว่าจะตรวจกับฉบับปัจจุบันและเจ้าพนักงานท้องถิ่น
