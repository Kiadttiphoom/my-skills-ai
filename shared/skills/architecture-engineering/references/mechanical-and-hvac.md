# งานระบบเครื่องกลและปรับอากาศ

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ภาระความร้อน การปรับอากาศ การระบายอากาศ ท่อลม พัดลม ท่อน้ำทิ้งแอร์ ท่อน้ำยา เสียง ตำแหน่งอุปกรณ์ และการบำรุงรักษา

## 2. หลักการสำคัญ (Fundamental principles)
- ภาระความร้อนมาจากแดดผ่านผนังและกระจก คน อุปกรณ์ แสงสว่าง และอากาศที่เข้า
- ขนาดเครื่องมาจากการคำนวณภาระ ไม่ใช่จากพื้นที่ห้องอย่างเดียว
- ต้องมีทางนำอากาศบริสุทธิ์เข้าและอากาศเสียออก โดยเฉพาะห้องซักรีดและครัว
- ท่อน้ำทิ้งแอร์ต้องลาดไปจุดระบายที่ถูกต้อง
- อุปกรณ์นอกอาคารต้องมีที่ว่างระบายความร้อนและทางซ่อม

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- การใช้งานและจำนวนคน
- ขนาดและวัสดุผนังกระจก
- โหลดอุปกรณ์ความร้อน
- ตำแหน่งวางเครื่องและทางท่อ
- ความสูงใต้คาน

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ระบุภาระความร้อนหลัก
2. เลือกระบบ (แยกส่วน รวมศูนย์ ระบายอากาศ)
3. วางตำแหน่งเครื่องและท่อ
4. ตรวจท่อน้ำทิ้งและท่อน้ำยา
5. ตรวจเสียงและการบำรุงรักษา

## 5. เชื่อมกับระบบอื่น
- โครงสร้าง: น้ำหนักและการสั่นของเครื่อง
- ไฟฟ้า: โหลดเครื่อง
- ประปา: ท่อน้ำทิ้งแอร์
- สถาปัตยกรรม: ฝ้าและทางซ่อม

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- น้ำหยดจากท่อน้ำทิ้งลาดไม่พอ
- เครื่องร้อนจากการระบายไม่พอ
- เสียงรบกวนจากตำแหน่งเครื่อง

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจความลาดท่อน้ำทิ้งก่อนปิดฝ้า
- ตรวจพื้นที่ซ่อมรอบเครื่อง

## 8. ความเข้าใจผิดที่พบบ่อย
- เครื่องใหญ่กว่าดีกว่าเสมอ (ใหญ่เกินทำให้ควบคุมความชื้นไม่ดี)

## 9. ความสัมพันธ์พื้นฐาน (ตำราทั่วไป ใช้เพื่อเข้าใจหลักการเท่านั้น ไม่ใช่สูตรกำหนดขนาด)
- ความร้อนที่ถ่ายผ่านผนัง Q = U × A × ΔT (U = ค่าการถ่ายเทความร้อนรวม, A = พื้นที่, ΔT = ผลต่างอุณหภูมิ)
- ความร้อนสัมผัสของอากาศ Q = ṁ × cp × ΔT (ṁ = อัตรามวล, cp = ความจุความร้อนจำเพาะ)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิง ASHRAE และข้อกำหนดไทยที่อ่านจริง
