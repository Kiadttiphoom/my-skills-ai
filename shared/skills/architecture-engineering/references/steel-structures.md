# โครงสร้างเหล็ก ไม้ ประกอบ และสำเร็จรูป

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
เหล็กโครงสร้าง รอยต่อ โครงถัก ไม้ โครงสร้างผสม และชิ้นส่วนสำเร็จรูป

## 2. หลักการสำคัญ (Fundamental principles)
- รอยต่อมักเป็นจุดวิกฤตของโครงสร้างเหล็กและสำเร็จรูป
- เหล็กต้องป้องกันสนิมและไฟตามการใช้งาน
- โครงถักทำงานดีเมื่อโหลดลงที่จุดต่อและมีค้ำยันป้องกันการโก่งเดาะ
- ไม้ต้องคำนึงถึงความชื้น ปลวก และแรงเฉือนที่จุดต่อ

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- การใช้งานและน้ำหนัก
- ช่วงพาดและความสูง
- สภาพแวดล้อมกัดกร่อน
- วิธียกและติดตั้ง

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. เลือกระบบตามช่วงพาดและงบ
2. กำหนดรอยต่อและค้ำยัน
3. กำหนดการป้องกันสนิมและไฟ
4. ตรวจการยกและความมั่นคงระหว่างติดตั้ง

## 5. เชื่อมกับระบบอื่น
- ฐานราก: เหล็กยึดและเพลทฐาน
- หลังคา: การรั่วและการขยายตัว
- อัคคีภัย: การป้องกันไฟ

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- สนิมที่รอยต่อและเพลทฐาน
- การโก่งเดาะเพราะขาดค้ำยัน
- รอยต่อติดตั้งผิดแบบ

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจรอยเชื่อมและสลักเกลียวก่อนปิดทับ
- ตรวจการป้องกันสนิม

## 8. ความเข้าใจผิดที่พบบ่อย
- เหล็กไม่ติดไฟจึงไม่ต้องป้องกันไฟ (แข็งแรงลดลงเมื่อร้อน)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิง AISC และมาตรฐานไทยที่อ่านจริง
