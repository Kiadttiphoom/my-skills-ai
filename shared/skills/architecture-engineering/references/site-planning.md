# การวางผังที่ดินและสภาพแวดล้อม

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
การสำรวจที่ดิน ระดับ ทิศ แดด ลม น้ำท่วม การระบายน้ำ ทางเข้า ระยะร่น และการวางอาคาร

## 2. หลักการสำคัญ (Fundamental principles)
- ข้อมูลที่ดินจริง (ระดับ ขอบเขต สาธารณูปโภค) มาก่อนการวางอาคาร
- น้ำต้องไหลออกจากอาคารและมีทางออกสู่ท่อหรือทางน้ำสาธารณะ
- ระดับพื้นอาคารสัมพันธ์กับระดับถนน ระดับน้ำท่วม และการระบายน้ำเสียแบบแรงโน้มถ่วง
- ที่ดินใกล้อาคารข้างเคียงต้องพิจารณาการขุด ฐานราก และผลกระทบ

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- รังวัดและระดับที่ดิน
- โฉนดและแนวเขต
- ระดับน้ำท่วมในอดีตและระดับน้ำใต้ดิน
- แนวท่อและสายสาธารณูปโภค
- สภาพถนนและทางเข้า
- ข้อกำหนดระยะร่นและผังเมือง

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. เก็บข้อมูลที่ดินและเพื่อนบ้าน
2. วิเคราะห์ทิศแดด ลม และน้ำฝนไหลผ่าน
3. ตรวจข้อกำหนดกฎหมายที่เกี่ยวข้อง
4. กำหนดระดับพื้นและทางระบายน้ำ
5. วางตำแหน่งอาคาร ทางเข้า ที่จอดรถ และระบบสาธารณูปโภค

## 5. เชื่อมกับระบบอื่น
- ธรณีเทคนิค: ระดับน้ำใต้ดินและสภาพดิน
- ประปา: จุดต่อท่อประปาและทางระบายน้ำเสีย
- ไฟฟ้า: ตำแหน่งมิเตอร์และเสาไฟ
- ฐานราก: อาคารข้างเคียงและสาธารณูปโภคใต้ดิน

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- น้ำท่วมขังเพราะระดับพื้นต่ำกว่าถนน
- ท่อระบายน้ำไม่มีจุดระบายออก
- ฐานรากชนสาธารณูปโภคใต้ดิน

## 7. จุดตรวจคุณภาพ (QC)
- เทียบระดับจริงกับแบบก่อนเริ่มงาน
- ตรวจแนวเขตและระยะร่นก่อนวางผัง
- ตรวจสาธารณูปโภคใต้ดินก่อนขุด

## 8. ความเข้าใจผิดที่พบบ่อย
- ที่ดินที่ถมสูงแล้วไม่ต้องพิจารณาน้ำท่วม (ต้องดูระดับเทียบพื้นที่โดยรอบและทางระบายน้ำ)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- เกณฑ์ผังเมืองและกฎหมายระยะร่นจากต้นฉบับ
- ข้อมูลน้ำท่วมจากหน่วยงานที่เชื่อถือได้
