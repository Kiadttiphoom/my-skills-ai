# วัสดุก่อสร้าง

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
คอนกรีต ปูน เหล็ก ก่ออิฐ อิฐมวลเบา ปูนก่อ ปูนฉาบ ปูนทราย กระเบื้อง กันซึม ฉนวน หลังคา สี ซีลแลนท์ ประตูหน้าต่าง

## 2. หลักการสำคัญ (Fundamental principles)
- วัสดุต่างชนิดขยายตัวและดูดความชื้นไม่เท่ากัน รอยต่อต้องรองรับการเคลื่อนตัว
- ลำดับติดตั้งสำคัญ: งานที่ต้องซ่อนในผนังหรือพื้นต้องเสร็จและทดสอบก่อนปิด
- ข้อมูลผู้ผลิตระบุเงื่อนไขติดตั้งเฉพาะผลิตภัณฑ์ ไม่ใช่มาตรฐานทั่วไป
- ความชื้นและน้ำฝนเป็นสาเหตุหลักของความเสียหายในเขตร้อนชื้น

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- ตำแหน่งใช้งานและสภาพแวดล้อม
- ข้อกำหนดผู้ผลิต
- มาตรฐานผลิตภัณฑ์ที่เกี่ยวข้อง (มอก. หรือเทียบเท่าที่ตรวจแล้ว)
- ความเข้ากันได้กับวัสดุข้างเคียง

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ระบุหน้าที่ของวัสดุในรายละเอียด
2. เลือกวัสดุตามสภาพแวดล้อม
3. ตรวจความเข้ากันได้และลำดับติดตั้ง
4. ตรวจเอกสารมาตรฐานและผู้ผลิต

## 5. เชื่อมกับระบบอื่น
- โครงสร้าง: น้ำหนักวัสดุ
- งานระบบ: การเจาะทะลุและการซ่อมแซม
- ก่อสร้าง: ลำดับงานและการบ่ม

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- ผนังร้าวที่รอยต่อวัสดุ
- กระเบื้องล่อนจากกาวหรือพื้นผิวไม่เหมาะ
- ฉาบหลุดล่อน

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจสภาพพื้นผิวก่อนปูหรือฉาบ
- ตรวจวันหมดอายุและวิธีผสมตามผู้ผลิต

## 8. ความเข้าใจผิดที่พบบ่อย
- วัสดุเทียบเท่า ASTM กับ มอก. ใช้แทนกันได้ทันที (ต้องมีการเทียบสเปกที่บันทึกไว้)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ
- ตรวจเลข มอก. และขอบเขตจากเว็บ สมอ. ก่อนอ้างอิง

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงมาตรฐานวัสดุที่อ่านจริง
