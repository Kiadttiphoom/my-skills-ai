# ฐานรากและเสาเข็ม

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ฐานรากตื้น ฐานแผ่ ฐานเสาเข็ม หัวเสาเข็ม คานคอดิน ตะเกียบเหล็กเสียบ และการเลือกระบบฐานราก

## 2. หลักการสำคัญ (Fundamental principles)
- ฐานรากถ่ายน้ำหนักจากเสาสู่ดิน เสาเข็มถ่ายผ่านฐานรากลงชั้นดินลึกกว่า
- ชนิดฐานรากขึ้นกับน้ำหนัก ชั้นดิน น้ำใต้ดิน ข้างเคียง และวิธีก่อสร้างที่ทำได้
- จำนวนและความยาวเสาเข็มมาจากน้ำหนักและผลทดสอบดิน ไม่ได้มาจากพื้นที่อาคาร
- จุดต่อหัวเสาเข็มกับฐานรากและเหล็กเสียบต้องมีรายละเอียดรับแรง ไม่ใช่แค่วางต่อกัน
- คานคอดินและคานรัดฐานช่วยเชื่อมฐานรากและควบคุมการเคลื่อนต่างกัน (ให้วิศวกรกำหนด)

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- รายงานดิน
- น้ำหนักที่ฐานรากแต่ละจุด
- ผังเสาและระยะ
- อาคารข้างเคียงและสาธารณูปโภค
- ข้อจำกัดทางเข้าและเครื่องจักรลงเข็ม

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ตรวจข้อมูลดินและน้ำหนัก
2. ประเมินทางเลือก: ฐานตื้น ฐานแผ่ เข็มตอก เข็มเจาะ
3. เทียบข้อดีข้อเสียต่อผลกระทบข้างเคียงและการก่อสร้าง
4. ระบุข้อมูลที่ยังขาด
5. ส่งวิศวกรโครงสร้างและธรณีเทคนิคคำนวณและยืนยัน

## 5. เชื่อมกับระบบอื่น
- ธรณีเทคนิค: ชั้นดินและน้ำใต้ดิน
- โครงสร้าง: ตำแหน่งเสาและโหลด
- ประปา: ท่อระบายน้ำเสียและบ่อตรวจเทียบระดับคานคอดิน
- ก่อสร้าง: ขั้นตอนขุด ลงเข็ม เทคอนกรีต

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- เข็มไม่ถึงชั้นดินที่ต้องการ
- หัวเข็มเอียงหรือคลาดตำแหน่ง
- ฐานรากรับแรงผิดจากตำแหน่งเสาคลาด
- ท่อระบายน้ำชนคานคอดินเพราะไม่ประสานระดับ

## 7. จุดตรวจคุณภาพ (QC)
- บันทึกการลงเข็มแต่ละต้น (ระดับ ตำแหน่ง ความเอียง)
- ตรวจเหล็กเสริมและตะเกียบก่อนเทคอนกรีต
- ตรวจระดับหน้าดินก้นหลุมก่อนเท

## 8. ความเข้าใจผิดที่พบบ่อย
- จำนวนเข็มหาได้จากพื้นที่อาคาร (ไม่ใช่)
- เสาเข็มแก้ปัญหาดินได้ทุกกรณี (ต้องดูผลข้างเคียงและการตอก)

## 9. ความสัมพันธ์พื้นฐาน (ตำราทั่วไป ใช้เพื่อเข้าใจหลักการเท่านั้น ไม่ใช่สูตรกำหนดขนาด)
- ความดันเฉลี่ยใต้ฐาน q = P / A (P = แรงแนวดิ่ง, A = พื้นที่ฐาน) เทียบกับค่าที่ผู้เชี่ยวชาญด้านดินกำหนด

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงฐานรากและเข็มที่อ่านจริง
- ตัวอย่างการเลือกฐานราก (มีสมมติฐานและข้อจำกัดชัด)
