# การประสานงานข้ามสาขา

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
กฎตรวจหาและแก้ปัญหาชนกันระหว่างสถาปัตยกรรม โครงสร้าง ประปา ไฟฟ้า แอร์ และดับเพลิง

## 2. หลักการสำคัญ (Fundamental principles)
- ปัญหาส่วนใหญ่เกิดที่ระดับ (elevation) และช่องทะลุ ไม่ใช่ผังแปลน
- คานลึกลดพื้นที่เดินท่อและความสูงฝ้า
- ท่อน้ำทิ้งแรงโน้มถ่วงมีข้อจำกัดเรื่องความลาด จึงชนข้อจำกัดโครงสร้างได้ง่ายที่สุด
- ทุกการแก้ปัญหาต้องระบุว่าใครต้องอนุมัติ

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- แบบทุกสาขาในระดับเดียวกัน
- ระดับพื้น ท้องคาน ฝ้า และท่อ
- รายการช่องทะลุ

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ซ้อนแบบทุกสาขา
2. ตรวจระดับท้องคานเทียบแนวท่อและท่อลม
3. ตรวจความลาดท่อน้ำทิ้งและระดับปลายทางเทียบฐานราก
4. ตรวจตู้ไฟและอุปกรณ์เทียบน้ำ
5. ตรวจทางซ่อมและทางเคลื่อนย้าย
6. บันทึกปัญหา ทางแก้ และผู้อนุมัติ

## 5. เชื่อมกับระบบอื่น
- ใช้ตรวจต่อเนื่องจากทุกไฟล์ใน references/

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- ท่อชนคาน
- ท่อทิ้งต้องต่ำกว่าคอดินแต่คอดินไม่ได้ลดระดับ
- แอร์ไม่มีจุดระบายน้ำ
- ตู้ไฟติดผนังเปียก

## 7. จุดตรวจคุณภาพ (QC)
- ตารางการชน (clash log) ที่มีสถานะ ผู้รับผิดชอบ ผู้อนุมัติ

## 8. ความเข้าใจผิดที่พบบ่อย
- ถ้าวาดแบบแต่ละสาขาถูก ประกอบกันจะถูกเอง (ไม่จริง)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- ตัวอย่าง clash log จากกรณีศึกษาห้องซักรีดและอาคารพาณิชย์
