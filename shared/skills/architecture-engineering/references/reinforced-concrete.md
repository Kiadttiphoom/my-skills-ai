# คอนกรีตเสริมเหล็ก

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
คุณสมบัติคอนกรีตและเหล็กเสริม การจัดเหล็กในเสา คาน พื้น ฐานราก ระยะหุ้ม การต่อทาบ แบบหล่อ การเท บ่ม และความบกพร่อง

## 2. หลักการสำคัญ (Fundamental principles)
- คอนกรีตรับแรงอัดดี เหล็กเสริมรับแรงดึง ทั้งสองทำงานร่วมกันด้วยแรงยึดเหนี่ยว
- ระยะหุ้มคอนกรีตปกป้องเหล็กจากสนิมและไฟ
- เหล็กปลอกและเหล็กลูกวนให้ความทึบตัว ต้านแรงเฉือนและยึดเหล็กหลัก
- ความยาวยึดเหนี่ยวและการต่อทาบต้องเพียงพอจึงถ่ายแรงได้
- คุณภาพการเท การเขย่า และการบ่มกำหนดความทนทานจริงไม่แพ้แบบ

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- แบบโครงสร้างและรายการเหล็ก
- เกรดคอนกรีตและเหล็กที่กำหนด
- สภาพแวดล้อม (ความชื้น สารเคมี)
- วิธีเทและลำดับการก่อสร้าง

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ตรวจแบบเหล็กเสริมกับผังและรายละเอียด
2. ตรวจแบบหล่อ ความมั่นคง และระยะหุ้ม
3. ตรวจการเตรียมงานระบบฝังในคอนกรีต
4. ควบคุมการเท เขย่า และบ่ม
5. ตรวจพื้นผิวและรอยร้าวหลังถอดแบบ

## 5. เชื่อมกับระบบอื่น
- ประปา ไฟฟ้า: ท่อและสลีฟที่ฝังในพื้นและคาน
- ฐานราก: เหล็กเสียบและหัวเข็ม
- สถาปัตยกรรม: ความหนาพื้นและคาบเกี่ยวกับงานกันซึม

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- รังผึ้งจากเขย่าไม่พอหรือเหล็กชิดเกิน
- ระยะหุ้มไม่พอทำให้เหล็กเป็นสนิม
- รอยร้าวจากหดตัวหรือบ่มไม่ดี
- ท่อฝังทำให้หน้าตัดอ่อนแอ

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจเหล็กเสริมก่อนเททุกครั้ง
- เก็บตัวอย่างและทดสอบคอนกรีตตามที่กำหนด
- บันทึกการเทและการบ่ม

## 8. ความเข้าใจผิดที่พบบ่อย
- เพิ่มเหล็กมากขึ้นแล้วปลอดภัยเสมอ (เหล็กชิดเกินทำให้เทไม่เต็มและอาจเปลี่ยนพฤติกรรม)
- การเจาะหรือสกัดเหล็กในคานหรือเสาทำได้ตามสะดวก (ต้องให้วิศวกรโครงสร้างอนุมัติ)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ
- ข้อกำหนดคอนกรีตและเหล็กเสริมใน มยผ./วสท. ให้ตรวจจากต้นฉบับ ข้ออ้าง มยผ. 1101–1106 ยังไม่ได้ตรวจ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงด้าน ACI และมาตรฐานไทยที่อ่านจริง
- รายละเอียดจัดเหล็กตัวอย่างพร้อมสมมติฐาน
