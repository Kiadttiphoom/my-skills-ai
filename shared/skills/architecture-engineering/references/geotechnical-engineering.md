# วิศวกรรมธรณีเทคนิค

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ชนิดดิน การสำรวจดิน รายงานเจาะสำรวจ น้ำใต้ดิน กำลังรับน้ำหนัก การทรุดตัว การขุดและผลกระทบอาคารข้างเคียง

## 2. หลักการสำคัญ (Fundamental principles)
- ดินคือวัสดุสามเฟส (เม็ดดิน น้ำ อากาศ) พฤติกรรมเปลี่ยนตามระดับน้ำและประวัติการรับน้ำหนัก
- ดินอ่อนและดินเหนียวทรุดตัวช้าตามเวลา (consolidation) ส่วนดินทรายตอบสนองเร็วกว่า
- การทรุดตัวต่างกัน (differential settlement) ทำให้อาคารเสียหายมากกว่าการทรุดเท่ากันทั้งหลัง
- ผลเจาะสำรวจเป็นข้อมูลจุดเฉพาะ ต้องพิจารณาความแปรผันตามพื้นที่
- การเจาะสำรวจและรายงานต้องทำโดยผู้เชี่ยวชาญที่ได้รับอนุญาต

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- รายงานเจาะสำรวจดิน (borehole log) พร้อมระดับและตำแหน่ง
- ผลทดสอบในสนามและห้องปฏิบัติการ
- ระดับน้ำใต้ดินและความผันแปรตามฤดู
- น้ำหนักอาคารและชนิดโครงสร้าง
- อาคารข้างเคียงและสาธารณูปโภค

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ตรวจว่ามีรายงานดินหรือไม่ และครอบคลุมตำแหน่งอาคารหรือไม่
2. อ่านชั้นดินและระดับน้ำ ระบุชั้นที่อ่อนและชั้นที่แข็ง
3. เปรียบเทียบพฤติกรรมกับน้ำหนักอาคาร
4. เสนอทางเลือกฐานราก พร้อมข้อมูลที่ยังขาด
5. ส่งต่อให้วิศวกรโครงสร้างและธรณีเทคนิคยืนยัน

## 5. เชื่อมกับระบบอื่น
- ฐานราก: ชนิดและความลึก
- โครงสร้าง: น้ำหนักและขีดจำกัดการทรุด
- ผังที่ดิน: น้ำใต้ดิน น้ำท่วม
- ก่อสร้าง: การขุดและการค้ำยัน

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- ออกแบบโดยไม่มีรายงานดิน หรือรายงานไม่ครอบคลุมตำแหน่งอาคาร
- ไม่คิดน้ำใต้ดินตอนขุด
- ทรุดตัวต่างกันจากดินถมหรือดินอ่อนไม่สม่ำเสมอ
- ขุดใกล้อาคารข้างเคียงโดยไม่ค้ำยัน

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจว่าผลเจาะตรงกับตำแหน่งอาคาร
- บันทึกระดับน้ำขณะขุดฐานราก
- ตรวจชั้นดินจริงเทียบรายงาน

## 8. ความเข้าใจผิดที่พบบ่อย
- ดินแถวนี้แข็ง ไม่ต้องเจาะสำรวจ (ต้องมีข้อมูลจริง)
- ค่าจากโครงการข้างเคียงใช้แทนได้ (ไม่ได้ เว้นวิศวกรยืนยัน)

## 9. ความสัมพันธ์พื้นฐาน (ตำราทั่วไป ใช้เพื่อเข้าใจหลักการเท่านั้น ไม่ใช่สูตรกำหนดขนาด)
- ความเค้นประสิทธิผล: σ' = σ − u (σ = ความเค้นรวม, u = แรงดันน้ำในช่องว่าง, หน่วย kPa)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงด้านการจำแนกดินและ SPT ที่อ่านจริง
- ข้อมูลลักษณะดินในภูมิภาคของโครงการ (ต้องมีแหล่งที่ยืนยัน)
