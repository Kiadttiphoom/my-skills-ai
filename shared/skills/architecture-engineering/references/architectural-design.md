# งานสถาปัตยกรรมและองค์ประกอบอาคาร

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
ผนัง หลังคา ผนังภายนอก ช่องเปิด การกันซึม ฉนวน ผิวสำเร็จ และการเชื่อมต่อกับโครงสร้างและงานระบบ

## 2. หลักการสำคัญ (Fundamental principles)
- อาคารในเขตร้อนชื้นฝนหนักต้องจัดการน้ำฝน ความร้อน ลม และความชื้นพร้อมกัน
- ชั้นกันน้ำและทางระบายน้ำต้องต่อเนื่อง จุดรอยต่อวัสดุต่างชนิดเป็นจุดเสี่ยงรั่วและแตกร้าว
- หลังคา รางน้ำ และท่อน้ำฝนต้องมีทางน้ำไหลลงต่อเนื่องถึงจุดระบายและเข้าถึงทำความสะอาดได้
- การบังแดดและทิศอาคารลดภาระความร้อนก่อนพึ่งเครื่องปรับอากาศ
- ผนังก่ออิฐเป็นส่วนไม่รับน้ำหนักในโครงสร้างกรอบคอนกรีต แต่ต้องมีการยึดเหนี่ยวและรอยต่อที่รองรับการเคลื่อนตัว

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- การใช้งานและจำนวนผู้ใช้
- ทิศ แดด ลม ฝนของที่ดิน
- ระบบโครงสร้างและระยะเสา
- งบประมาณและวัสดุที่หาได้
- ข้อกำหนดผังเมืองและระยะร่น

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ระบุการใช้งานและพื้นที่ใช้สอย
2. วางผังและทิศทางโดยพิจารณาแดดและลม
3. กำหนดรูปแบบหลังคาและทางระบายน้ำฝน
4. เลือกระบบผนังและช่องเปิด
5. กำหนดจุดกันซึมและรอยต่อ
6. ตรวจความสอดคล้องกับโครงสร้างและงานระบบ

## 5. เชื่อมกับระบบอื่น
- โครงสร้าง: ระยะเสา คานเปิดช่อง ผนังรับแรงหรือไม่
- ประปา: พื้นเปียก ความลาดเอียง จุดระบายน้ำ
- ไฟฟ้า: ตำแหน่งตู้ สวิตช์ เต้ารับ ในพื้นที่เปียก
- แอร์: จุดวางคอนเดนเซอร์และท่อน้ำทิ้ง

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- รั่วซึมที่รอยต่อหลังคา ผนัง และพื้นเปียก
- รอยร้าวผนังที่รอยต่อวัสดุต่างชนิด
- น้ำขังบนดาดฟ้าจากความลาดเอียงไม่พอหรือท่อตัน
- ความชื้นสะสมในผนังและฝ้า

## 7. จุดตรวจคุณภาพ (QC)
- ตรวจการลาดเอียงและทดสอบขังน้ำก่อนปูผิว
- ตรวจรอยต่อและการยึดวัสดุก่อนฉาบหรือปิดทับ
- ตรวจทางระบายน้ำฝนว่าเข้าถึงทำความสะอาดได้

## 8. ความเข้าใจผิดที่พบบ่อย
- ผนังก่ออิฐช่วยรับน้ำหนักอาคารกรอบคอนกรีต (โดยปกติไม่ใช่ ต้องให้วิศวกรโครงสร้างยืนยัน)
- กันซึมชั้นเดียวแก้ได้ทุกจุด (รอยต่อและรายละเอียดสำคัญกว่า)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- แหล่งอ้างอิงด้านรายละเอียดกันซึมและผนัง
- กรณีศึกษาบ้านชั้นเดียวและอาคารพาณิชย์
- เกณฑ์ผังเมืองและระยะร่นที่ตรวจจากต้นฉบับ
