# การวางผังพื้นที่ใช้สอยและการสัญจร

> สถานะ: ไฟล์เริ่มต้น เนื้อหาเป็นหลักการวิศวกรรมทั่วไป ไม่มีค่าออกแบบ ไม่มีเลขข้อกำหนด ทุกค่าตัวเลขและข้อกำหนดต้องเพิ่มหลังอ่านแหล่งจริงและบันทึกใน `RESEARCH_SOURCES.md` (ใส่ Source ID กำกับ)

## 1. ขอบเขต
สัดส่วนห้อง การจัดโซน ทางสัญจร บันไดและทางลาด ประตูหน้าต่าง ความปลอดภัยและการเข้าถึง เสียง

## 2. หลักการสำคัญ (Fundamental principles)
- เริ่มจากกิจกรรมและจำนวนผู้ใช้ ไม่เริ่มจากขนาดห้องเป็นตัวเลข
- แยกโซนเปียกกับโซนแห้ง รวมท่อและจุดระบายให้สั้นและเข้าถึงได้
- ทางสัญจรต้องรองรับการเคลื่อนย้ายคนและอุปกรณ์ รวมถึงการหนีไฟ
- ตำแหน่งเสา ผนัง และประตูต้องไม่ขัดการใช้เฟอร์นิเจอร์หรือเครื่องจักร

## 3. ข้อมูลนำเข้าที่ต้องมี (Required inputs)
- โปรแกรมการใช้งาน
- จำนวนผู้ใช้และอุปกรณ์
- เครื่องจักรหรืออุปกรณ์ที่ต้องมีทางเข้าซ่อม
- ความต้องการเข้าถึงสำหรับผู้พิการและผู้สูงอายุ

## 4. ลำดับการให้เหตุผล (Reasoning workflow)
1. ระบุกิจกรรมและความสัมพันธ์ระหว่างพื้นที่
2. จัดโซนและทางสัญจร
3. กำหนดตำแหน่งบันได ทางลาด ประตู
4. ตรวจแสง ลม เสียง
5. ตรวจสอบกับโครงสร้างและงานระบบ

## 5. เชื่อมกับระบบอื่น
- โครงสร้าง: ระยะเสาและช่วงคาน
- ประปา: ตำแหน่งห้องน้ำและพื้นที่เปียก
- อัคคีภัย: ทางหนีไฟและระยะทางเดิน
- แอร์: ตำแหน่งเครื่องและท่อ

## 6. ข้อบกพร่องและรูปแบบความเสียหายที่พบบ่อย
- เสาขวางทางเดินหรือจุดจอดรถ
- ห้องเปียกกระจัดกระจาย ท่อยาวและเข้าถึงยาก
- ทางเดินแคบกว่าที่อุปกรณ์เคลื่อนที่ผ่านได้

## 7. จุดตรวจคุณภาพ (QC)
- เดินเส้นทางผู้ใช้บนแบบ
- ตรวจทางเข้าซ่อมอุปกรณ์และทางเคลื่อนย้ายเครื่องออก

## 8. ความเข้าใจผิดที่พบบ่อย
- ขนาดห้องตามแบบสำเร็จรูปใช้ได้ทุกกรณี (ขึ้นกับการใช้งานจริง)

## 10. กฎหมายและมาตรฐานไทยที่ต้องตรวจ
- ตรวจกฎกระทรวงตามพระราชบัญญัติควบคุมอาคาร ข้อบัญญัติท้องถิ่น และมาตรฐาน มยผ./วสท. ที่เกี่ยวข้อง จากต้นฉบับ (ดู `thailand-building-regulations.md`) ห้ามสรุปเลขข้อหรือตัวเลขจากความจำ
- เกณฑ์ขนาดห้อง บันได ทางลาด และการเข้าถึงสำหรับคนพิการ ให้ตรวจจากกฎกระทรวงและมาตรฐานที่เกี่ยวข้องจากต้นฉบับ

## 11. สถานะแหล่งอ้างอิง
- ยังไม่มีแหล่งที่อ่านจริงสำหรับไฟล์นี้ (ดู `RESEARCH_SOURCES.md`)
- ป้ายหลักฐานเริ่มต้นของเนื้อหาในไฟล์นี้: RULE OF THUMB / หลักการทั่วไป จนกว่าจะมี Source ID

## 12. งานที่ต้องเพิ่มหลังวิจัย
- เกณฑ์ขนาดและการเข้าถึงที่ตรวจจากต้นฉบับ
- กรณีศึกษาห้องซักรีดและร้านค้า
